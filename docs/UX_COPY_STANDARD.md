# Standar Bahasa UI Enterprise

Setiap heading wajib menjelaskan objek dan tujuan bisnis, bukan hanya singkatan atau istilah internal.

- Gunakan Bahasa Indonesia sebagai label utama; istilah umum seperti BOM, JSA, EAC, NCR, CAPA, GRNI, AP, dan AR harus diperluas pada kemunculan pertama.
- Setiap workspace menjelaskan alur proses, prasyarat, dan hasil transaksi.
- Tombol memakai kata kerja dan hasil yang spesifik, misalnya `Kirim untuk Persetujuan`, `Terbitkan Permit`, atau `Posting Jurnal Piutang`.
- Empty state menjelaskan mengapa daftar kosong dan tindakan yang harus dilakukan berikutnya.
- Hindari label generik seperti `Process`, `Activate`, `Post`, `Action`, `Movement`, atau `Investigation` tanpa objek yang diproses.
- Status teknis boleh disimpan dalam bahasa Inggris di database, tetapi label UI harus diterjemahkan secara konsisten.
- Akronim ISO/QMS tidak boleh digunakan untuk menyiratkan sertifikasi. Aplikasi hanya menyimpan kontrol dan evidence penerapan.
