# نظام Graha Pondasi ERP

نظام ERP متكامل لشركات الأساسات والـ bored pile. يغطي دورة العمل من المناقصات والعقود إلى التنفيذ الميداني والتصنيع والمشتريات والمخزون والمحاسبة الإندونيسية وQMS/HSE وإدارة الوثائق والموافقات والتوقيع الرقمي ضمن سجل بيانات قابل للتدقيق.

**اللغات:** [English](README.en.md) · [Bahasa Indonesia](README.md) · [العربية](README.ar.md)

## التقنية

- Laravel 13 وPHP 8.3 وMySQL 8.4
- AdminLTE 4.9.1 مع Bootstrap 5.3 وJavaScript أصلي وVite
- Blade وTailwind CSS v4 للشاشات الحالية
- PHPUnit وLaravel Pint وبنية Modular Monolith
- عزل صارم بين الشركات وصلاحيات حسب العضوية والدور

## تكامل AdminLTE 4.9.1

يستخدم الغلاف المحمي الحزمة الرسمية `colorlibhq/adminlte-laravel` وأصول AdminLTE 4.9.1. الملفات `resources/css/adminlte.css` و`resources/js/adminlte.js` تربط Bootstrap وAdminLTE مع JavaScript الخاص بالتطبيق، مع الحفاظ على قائمة Graha المبنية على الصلاحيات ودعم الشاشات الصغيرة وRTL.

```bash
composer install --no-interaction
copy .env.example .env
php artisan key:generate
php artisan migrate --seed
npm ci
npm run build
php artisan serve
```

## سير العمل والتشغيل

`مناقصة ← تقدير ← فوز ← ترسية ← توقيع ← تسليم ← مشروع نشط ← شراء واستلام ← مخزون وتنفيذ ميداني ← اختبار وقبول ← فوترة مرحلية ← قيد محاسبي ← تكلفة وإغلاق`

شغّل `php artisan queue:work --tries=3` و`php artisan schedule:work` في الإنتاج. تشمل المهام المجدولة النسخ الاحتياطي وانتهاء الأدلة وتنبيهات المخزون ومهل الموافقات وNCR/CAPA. الملفات الخاصة محمية بالتفويض، وبيانات المزودين يدخلها المستخدم وتُشفّر ولا تُثبت داخل الكود.

راجع [DEPLOYMENT.md](DEPLOYMENT.md) وملفات `deploy/` وتعليمات التشغيل داخل `docs/` لمزيد من التفاصيل.
