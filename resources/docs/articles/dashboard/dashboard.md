## Ringkasan
Dashboard merangkum kondisi bisnis hari ini: performa pendapatan (billing posted), proyek berjalan, approval menunggu, dan pile progress.

## Bagian layar
| Widget | Sumber data |
|---|---|
| Performa Pendapatan | Progress billing status posted, grup per bulan |
| Proyek Berjalan | Proyek status active/in_progress |
| Menunggu Persetujuan | Approval request pending |

## FAQ
**Angka pendapatan kecil?** Hanya billing yang sudah diposting yang dihitung; billing pending approval tidak termasuk.
