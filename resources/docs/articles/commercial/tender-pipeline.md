## Alur
```workflow
Draft -> Bid Decision -> Submit -> Evaluation -> Won/Lost -> Contract
```

## Langkah membuat tender
1. Buka **Tenders** ? tombol tambah.
2. Isi nomor, klien, estimasi owner, nilai bid.
3. Setelah pengumuman, rekam **outcome** + pemenang.

## Status / workflow
`won` dapat dikonversi menjadi kontrak & proyek lewat tombol Convert.
